## 🚀 Featured Projects

### 🤟 AI-Powered Sign Language Platform

A full-stack platform for Indian and American Sign Language recognition,
translation, and interactive AI-assisted practice.

- Real-time sign recognition using MediaPipe and an MLP classifier
- Sign-to-text-to-speech translation with LLM-based grammar correction
- Dynamic Time Warping (DTW) for pose scoring and finger-level feedback
- Four FastAPI services and a React frontend
- Offline LLaMA 3.2 integration through Ollama

**Stack:** React · FastAPI · Python · MediaPipe · LLaMA 3.2 · Ollama

### 🚦 MultiAgent AI Traffic Management System

An AI-powered traffic management system designed to predict congestion
and optimize traffic signals using real-time traffic information.

- OpenCV and supervised machine learning for traffic analysis
- Dynamic traffic signal optimization
- AWS Lambda, DynamoDB, SNS, and Bedrock integration
- TomTom API integration for traffic data and routing

**Stack:** Python · OpenCV · AWS · Machine Learning · TomTom API

### 🧬 MedShield AI — Drug-Gene Interaction Classifier

An AI healthcare prototype that classifies drug–gene interaction risks
as Safe, Risk, or High-Risk.

- Deep learning inference using PyTorch
- Molecular feature extraction using RDKit
- Flask REST API and responsive web frontend
- Exportable prediction reports in CSV and JSON

**Stack:** Python · PyTorch · Flask · RDKit · JavaScript · Bootstrap
